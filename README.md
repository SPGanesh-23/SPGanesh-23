**`Solar Intelligence · Renewable Energy · Machine Learning`**

> *The sun generates 430 quintillion joules every hour. SolarVision helps us use it smarter.*

SolarVision is a full-stack ML application that forecasts solar power output by fusing historical meteorological archives with real-time atmospheric data. Built during the **1M1B Global Green Internship**, it provides actionable intelligence for renewable energy planning through a live interactive dashboard.

<div align="center">

| Feature | Detail |
|---------|--------|
| ⚡ Prediction Engine | ML model trained on historical solar + weather patterns |
| 🌤 Real-time Data | NASA POWER API · OpenWeatherMap API |
| 📊 Live Dashboard | Energy forecast visualization + performance metrics |
| 🌍 Impact | Supports sustainable energy planning decisions |
| 🚀 Deployment | Live web app hosted on Render |

</div>
